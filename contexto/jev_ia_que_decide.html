Duas formas de pensar
Daniel Kahneman

THINKING, FAST AND SLOW · 2011 · ED. BRASILEIRA: OBJETIVA, 2012

A mente como dois personagens

Sistema 1 roda o tempo todo, no automático, e resolve a maior parte do nosso dia.
Sistema 2 é o esforço consciente: caro, lento — e por isso "preguiçoso". Só entra quando é chamado.
Boa parte dos nossos erros nasce do S1 respondendo onde o S2 deveria ter assumido — os vieses.

Paráfrase das ideias centrais do livro.

:Dflowgrammers|ed

Sistema 1 × Sistema 2

Sistema 1

Rápido · automático · sem esforço · intuitivo

  • Quanto é 2 + 2
  • Perceber hostilidade num tom de voz
  • Ler uma placa na sua língua
  • Dirigir numa estrada vazia

Sistema 2

Lento · deliberado · esforçado · lógico

  • Quanto é 17 × 24
  • Estacionar numa vaga apertada
  • Preencher a declaração do IR
  • Comparar dois contratos cláusula a cláusula
:Dflowgrammers|ed
O que importa pra arquitetura
S1 decide.
S2 audita.

O cérebro não pensa devagar o tempo todo.
Seu software também não deveria.

Atenção é escassa — o S2 é economizado por design.
S1 é rápido porque responde dentro de padrões conhecidos.
Quando o padrão não fecha — surpresa, risco, conta difícil — o S2 assume.

Síntese. LLM com reasoning é um Sistema 2 artificial. O desperdício está em usá-lo pra trabalho de Sistema 1.

Kahneman aplicado

A PIRÂMIDE

DE DECISÃO

Regra: cada decisão no nível mais barato que resolve — e sobe só quando precisa.

REFLEXO — if · regex · switch

SISTEMA 1 — Jev

Escolhe entre opções que você definiu, em milissegundos, tolerando variação no input.

PARTE 2

Jev: o modelo
que não gera
texto

Lançado pela TypeSafe em setembro de 2026: recebe estado + perguntas tipadas e devolve decisões com probabilidade.

:Dflowgrammers|ed
Ficha técnica

JEV

SYSTEM ONE

O nome homenageia William Stanley Jevons: quando o custo de algo despenca, o consumo explode.

Entrada — state (texto, JSON ou lista) + questions tipadas

Saída — JSON validado: escolha, probabilidades e confiança

Endpoint — POST api.typesafe.ai/v1/systemone · modelo jev-latest

Treino — RLCD: reforço para decisões calibradas, no lugar de RLHF

Não faz — prosa, código, explicação, imagem, áudio

:Dflowgrammers|ed

Feito pra criar × feito pra decidir

LLM generativo

Forçado a decidir.

  • JSON "na marra": structured output + parser + retry
  • Cada chamada pode variar — e o provedor troca o modelo
  • Paga input e output; leva segundos
  • Você usa uma fração do que está pagando

Jev

Decidir é o produto.

  • Só escolhe dentro do que você definiu
  • JSON válido de fábrica, sem output parser
  • Consistente: input parecido, decisão parecida
  • Output grátis; responde em milissegundos
:Dflowgrammers|ed
O ponto que mais importa
CONSISTÊNCIA

vale mais que

DETERMINISMO
Determinismo — mesma entrada, mesma saída. Uma palavra diferente e tudo pode virar.
Consistência — decisões semelhantes mesmo quando o input muda uma palavra ou outra.
Mais robusto que regex e cascata de ifs; mais estável que um LLM que "cria" a cada chamada.

Na prática: 100 chamadas não dão 100 respostas idênticas — mas dão respostas muito próximas.

Fonte: FAQ da TypeSafe (set/2026)

PARTE 3

Choice,
Score e
Noul

Toda pergunta vira um de três tipos — e todos voltam com probabilidade.

:Dflowgrammers|ed
Tipos de resposta

AS 3 PERGUNTAS

DO JEV
CHOICE — múltipla escolha

Escolhe 1 entre até 255 opções descritas por critérios. Devolve a escolha, a probabilidade de cada opção e a confiança.

ex.: suporte técnico · acesso · comercial

SCORE — nota em escala

Encaixa o estado numa escala de 2 a 10 níveis que você descreve. Devolve a nota ponderada (ex.: 3,7) e a distribuição.

ex.: urgência do atendimento de 0 a 4

NOUL — sim/não com grau

Probabilidade de 0 a 1 de uma afirmação ser verdadeira. Um booleano que diz o quanto tem certeza.

ex.: "o aluno quer pedir reembolso?"

Fan-out: várias perguntas na mesma chamada, sobre o mesmo estado — e uma não contamina a outra.

Do número à ação
CONFIANÇA
VIRA REGRA

Quem define o limiar é o negócio — não o modelo.

≥ 0,85 — executa sozinho: tag, rota, card no pipeline.
0,60 a 0,85 — sobe pro Sistema 2: um LLM decide ou escreve.
< 0,60 — fila humana.

Atenção: calibração é propriedade da população, não garantia por chamada. Os limiares acima são ponto de partida — ajuste com dados rotulados seus.

Por que velocidade importa
SEGUNDOS

viram

MILISSEGUNDOS

E a decisão sai do batch noturno pro fluxo em tempo real.

LLM com reasoning leva segundos por item. O Jev declara 70–500 ms — e mediu 178 ms de mediana no jev-ultrafast.
Fila de 20 mil contatos: de dias pra horas — e menos timeout.
Dá pra decidir dentro do request do usuário, não só em segundo plano.

Ceticismo saudável: a TypeSafe declara 193,6× mais rápido e 444,6× mais barato que modelos de fronteira em workflows — benchmark interno, sem validação de terceiros.

O paradoxo de Jevons

Quando decidir fica barato,
você para de racionar inteligência.

O custo era o filtro: classificava-se uma mensagem em cada cem.
Agora dá pra classificar todas — e é aí que o volume (e a conta) explode.

Planeje o volume, não só o preço unitário.

A lição que vale pra qualquer agente
SAÍDA DO MODELO
NÃO É COMANDO

O que a gente cobra em setor regulado — num repo de sete arquivos.

A saída nunca vira seletor, coordenada, shell ou JavaScript — só um índice de elemento observado.
DONE não é prova. O resultado é verificado de forma independente.
Nunca repetir uma mutação (clique, digitação). Loga a execução antes de observar.
Texto da página é dado, não instrução — defesa contra prompt injection.

Fonte: AGENTS.md, README e docs/design.md do jev-ultrafast (MIT)

Contrato,
limiar e rota.

O mesmo roteamento, antes e depois

Antes

AI Agent + Structured Output Parser

  • Prompt pedindo JSON + parser + retry
  • Às vezes um segundo modelo só pra validar
  • Segundos por item; paga entrada e saída
  • Quebra quando o provedor muda o modelo

Depois

HTTP Request (Jev) + Switch

  • JSON tipado de fábrica
  • N perguntas numa chamada só
  • Milissegundos por item; paga só a entrada
  • Probabilidade logada pra auditar e recalibrar

BALA DE PRATA

Sistema 1 erra rápido também. Kahneman avisou.

Gerar texto — e-mail, resumo, tradução, código: é trabalho de S2.
Explicar a decisão — o Jev não justifica, só decide.
Conhecimento fora do state — ele só julga o que você mandou.
Imagem, áudio, vídeo — entrada é só texto e JSON.
Volume baixo — poucas mil decisões por ano? Um LLM resolve.

Números de fabricante: benchmarks internos, e a própria TypeSafe diz que não consegue provar que o preço não é subsidiado.
